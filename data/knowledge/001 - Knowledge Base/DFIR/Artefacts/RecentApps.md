# Context
All the apps that have been started by the user
Show only the applications, no documents or else
Based on the registry key "NTUSER.DAT\Software\Microsoft\Windows\CurrentVersion\Application Usage\RecentApps"
# Usage
- Collect application name, path, last execution, ...
