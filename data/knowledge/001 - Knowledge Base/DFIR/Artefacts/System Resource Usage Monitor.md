# Context
SRUM register all systems ressources to keep tracability (network, CPU, battery, Memory, ...)
# Usage
Can be useful when you want to follow what an app did during time : 
- When a process started to exfiltrate data can be indicated by his network usage exploding
- A ransomware being started can be determined by a high usage in the memory or CPU at the time it started encrypting files
