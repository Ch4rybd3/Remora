# Context
BITS is a Microsoft protocol used to transfer updates between computers without needing to have internet access or surcharge bandwith
For example, you could use BITS to deploy a windows MAJ to a single workstation in a company branch, then this machine would wend the update to all the others without using the whole bandwith.
But it is also used to exfiltrate data
