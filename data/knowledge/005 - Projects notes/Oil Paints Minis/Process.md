

# Selecting a color scheme
- Look for inspiration on the web
- Find the colors you need on the color wheel

# Setup
- Preparing the palette
- start mixing the colors we want
# Pre-glaze
- thin it just enough so it can fill the cracks and recesses, but not too much as it will be less effective
- Go for the color of the basecoat, even if you use multiple colors (for OSL for example), use the base coat from where you want to paint
- Let it stain (10/30mn)
- Wipe it off using makeup sponge/a blending brush/Q-tips/...



Tips : 
- Make a filbert brush by cutting the edge of a flat one
