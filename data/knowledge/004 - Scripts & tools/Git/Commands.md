# Commands
## Basics
```Shell
# Pull the commit mades on the branch from the repository to get up to date with other changes
git pull
# Add the current changes to be commited (here, the whole directory)
git add .
# Make a commit with a message
git commit -m "Fixed the typo in the README.md"
# Push the commit into the repository
git push
```
